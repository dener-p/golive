Golive

Share your screen with friends over a private link. WebRTC carries the media peer-to-peer — nothing passes through the server.

Host

Share your screen, window or tab and send the room link to friends.

Watch

Enter the room code you were given.

A room code is 3–24 characters: a–z, 0–9, - or _.

How it works

  1. The host creates a room and shares the link (or the QR code) with the viewers.
  2. Video and audio travel directly between the browsers (WebRTC peer-to-peer). The server only helps set up the connection — it never sees or records your screen.
  3. The host sends one stream per viewer, so upload bandwidth sets how many can watch and at what quality.

What it needs

  • A current browser. To host, Chrome, Edge or Firefox on desktop (screen sharing is limited in Safari).
  • A secure address (HTTPS) to capture the screen — this page already uses HTTPS.
  • There is no relay server (TURN), so both sides must connect directly. Strict NAT or corporate firewalls can block it; IPv6 helps.
  • Screen audio depends on the browser and source: a tab or the whole screen in Chrome (Windows, ChromeOS, macOS 14.2+). Firefox and Safari don't share it.
  • Up to 8 viewers per room (default).
