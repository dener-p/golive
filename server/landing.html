golive

Let your screen out — direct P2P, AV1, no relay. Viewers just open your link.

Watch

No install needed. Open a room link in any desktop browser (Chrome/Edge/Firefox).

Host

You stream straight to each viewer — the server only introduces you. Windows only for v1.

checking for the latest build…
  1. Run the installer, then launch golive helper (a console window opens).
  2. It prints your viewer link and host page. Keep the window open while streaming.
  3. Share the viewer link. Pick your screen, press Start streaming.

Needs Windows with an AV1-capable GPU (AMD Radeon 6000+, NVIDIA RTX 40/50) or a decent CPU (software encoder fallback) and ~4000 kbit/s upload per live viewer.

First-run note: the installer isn't code-signed yet, so Windows SmartScreen may warn “unknown publisher” — click More info → Run anyway. Signing is on the roadmap.

No middleboxes, no accounts

Direct WebRTC P2P with plain STUN — v1 deliberately has no relay/TURN, no recording, no SFU, no browser extensions. If a network pair can't connect directly, you'll see “Direct connection failed”. Host identity is bound via a room key you control.

Privacy: golive stores your room key and, when you bind a room to it, your Discord identity — nothing else. No data passes through the server beyond signaling.
